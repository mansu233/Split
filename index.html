Participants
A New Person Can Join At Any Time By Adding Them With Their Actual Join Date. A Leave Date Can Be Added Later. An Expense Includes A Participant Only When: Join Date ≤ Expense Date ≤ Leave Date. If Leave Date Is Blank, The Participant Remains Active.
Contributions
A Participant Can Contribute Any Number Of Times. Existing Contribution Logs Cannot Be Directly Deleted.
Expenses
The Expense Date Controls Who Shares The Expense. Existing Expense Logs Cannot Be Directly Deleted.
Security
The PIN Protects Participant Corrections And Financial Log Corrections. There Is No Normal Delete Button For Historical Contributions Or Expenses.
